# 以有限资金群体和统一价批量竞价形成行情

2026-10-01。首版包含策略经营、小时短线和资金博弈，玩家无需竞争毫秒级委托顺序。选择“经营与事件状态 → 公开信息与异质预期 → 有限账户委托 → 每日 16 次统一价批量竞价 → 持仓和行为反馈”，两个市场共用机制，仅交易制度和资金结构不同。该选择取代初期研究偏向的连续逐档撮合候选；详细规则由 [玩法模型设计](../design/gameplay-market-model.md) 和其链接的规则文档定义。

## 取舍

- 因子直接产生价格、再附加滑点：简单，但无法把有限对手盘和玩家影响可靠地纳入同一价格形成过程，排除。
- 连续价格时间优先撮合：适合逐笔与排队策略；本项目小时级操作没有相应收益，却必须定义细粒度到达顺序，首版不选。
- 统一价批量竞价：同一批委托共同确定价格和数量，能够表现有限承接、价格冲击、错过机会与部分成交，且无需赋予 NPC 更快的反应通道，选用。

## 后果

每批所有成交使用同一价格，不再按逐档均价结算或附加冲击费；界面使用历史申报失衡，不能冒充连续市场的主动买卖统计。新闻在本批决策窗口先公开，玩家与 NPC 基于同一公开快照撤改委托。这个机制是虚构市场的设计选择，不宣称复刻现实全天交易，也不宣称消除了所有策略操纵；同价分配、信息公平和反套利场景必须按规则验证。

数值参数尚未校准；更改主题持续时间或账户规模不需要推翻本决定，改回连续撮合则需要重新检查执行体验、时间公平和相关验证场景。
