# 黑色交易终端 UI 核验

日期：2026-10-01。范围：固定示例数据驱动的浏览器 UI；不是市场模拟、P0 技术基线或 P2/P4 阶段验收。

## 交付与运行

- 黑色背景、交易终端三栏布局、资产组合和公开资讯页面。
- 默认红涨绿跌；反向预设及任意两种自定义颜色，立即应用并在当前浏览器保存。
- 自选、搜索、市场筛选与排序、选股、日/小时 K、均线开关、键盘图表查看、公司资料、委托预览及关联导航。
- 未增加应用依赖或修改 `packages/sim-core`。外观偏好与固定展示数据均留在 Web 层。

运行 `npm run dev` 后访问 `http://127.0.0.1:5173/`。生产构建入口为 `npm run check`，静态预览为 `npm run preview`。

## 实际检查

环境为 Windows、Codex 内置浏览器。页面检查使用开发服务和原生 UI/DOM 交互，不是截图比对的自动测试套件。

| 检查 | 实际结果 |
|---|---|
| `npm run check` | 两工作区、Vite 配置类型检查和 Web 生产构建通过 |
| `git diff --check` | 通过 |
| `npm run preview` | 4173 端口静态预览可打开，12 只样本、黑底、默认涨跌色和外观弹窗正常，无捕获的 error/warn 日志 |
| 黑底与默认配色 | 初始上涨数字 `rgb(241, 105, 117)`，下跌数字 `rgb(54, 201, 155)`；数字、图表、量柱使用同一组变量 |
| 反向预设 | 绿涨红跌后上涨数字及蜡烛切为绿色，下跌数字切为红色；刷新保留 |
| 自定义与恢复 | 上涨 `#f0c45c`、下跌 `#62a6ed` 实际应用；刷新后仍保留；恢复默认有效。颜色输入改用原生 `input` 事件以支持即时反馈 |
| 筛选与选股 | 乙市场显示 6 只；搜索“琥珀”仅显示 1 只，选股后标题、图表和保护价更新为该股 |
| 自选与排序 | 加入澜川能源后自选为 4 只；按涨幅排序得到 3.48%、2.67%、2.22%、−1.21% |
| 图表 | 日/小时切换、均线开关有效；小时末根明确“进行中”；左右键查看可移动到世界日 286，Escape 恢复默认展示 |
| 涨跌幅语义 | 修正开收方向与前收涨跌幅方向混用：A001 世界日 234 的 −0.08% 用跌色，世界日 259 的 +0.22% 用涨色 |
| 委托输入 | 零价格、小数股数禁用预览；无持仓股票卖出显示可售不足；分批计划预览含方向、股数、保护价、金额和结束小时，并明确没有提交 |
| 跨页导航 | 资产组合显示示例现金/持仓；点击持仓股票返回行情并清除遗留筛选；资讯详情可跳转关联股票 |
| 弹窗 | 配色与委托弹窗可打开/关闭，Escape 有效，配色弹窗初始焦点在关闭按钮 |
| 响应式 | 检查 1440×1000、1024×900、390×844；页面无横向溢出；窄屏行情与持仓在各自区域滚动，图表按实际宽度布局以保留可读坐标字 |
| 浏览器日志 | 核查时无捕获的 error/warn 日志 |

本轮实际截图保存在被 Git 忽略的 `artifacts/verification/ui-preview/`：`desktop.jpg`、`mobile.jpg`、`appearance.jpg`。这些只证明界面外观，不作为撮合正确性、经济稳定性或性能证据。

## 剩余限制

固定样本含 12 股，不是 40/200 股生成结果；真实撮合、资源冻结、费用、成交回执、预热、时钟推进、游戏存档、赛季与生涯仍未实现。自选在当前会话有效；只有配色保存至本机。存储失败处理经代码核查，本轮未进行浏览器禁用存储故障注入。尚未完成 Safari/Firefox 实机、多浏览器矩阵、全量无障碍、手机完整交互或性能预算测量。阶段和任务状态保持未开始。
