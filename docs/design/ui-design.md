# 交易终端界面设计

日期：2026-10-01。范围：可运行的浏览器 UI 预览；不代表 P0、P2 或 P4 通过。

## 布局和视觉

以桌面交易软件为参考，使用黑色页面（`#08090b`）、近黑面板（`#101215`）和细灰边界。浅绿色只用于导航、选中状态及普通主按钮；价格的颜色与品牌色分开。数字采用等宽字体和固定小数位，涨跌同时显示正负号。

- 顶部：交易终端、资产组合、市场资讯；外观设置与使用说明。
- 概况栏：两个虚构市场的示例指数、样本涨跌分布、示例账户净值。
- 交易终端：左侧行情筛选、自选和搜索；中部个股资料、图表与持仓；右侧委托表单和市场快讯。
- 资产组合：现金/股票配置、总现金/可用/冻结现金、持仓市值和持有/可售股份。
- 市场资讯：公开信息流、文章详情和关联股票入口。

窄屏下行情列表改为横向浏览，图表、持仓、委托和快讯顺序排列；持仓表格在自身区域横向滚动。这是基础适配，不替代后续手机完整体验或多浏览器验收。

## 涨跌颜色

默认上涨 `#f16975`、下跌 `#36c99b`。外观弹窗提供红涨绿跌、绿涨红跌、自定义两种颜色、效果预览和恢复默认。

`--up` / `--down` 统一覆盖行情数字、指数、涨跌分布、盈亏、K 线、成交量和买卖方向提示。蜡烛颜色根据开收关系，涨跌幅颜色根据其正负，平盘为中性灰；均线保留各自颜色。颜色即刻应用，保存到 `localStorage` 的 `big-a.appearance.v1`。读取时校验两种十六进制颜色，数据损坏或存储不可用时不影响页面使用；保存失败会在设置内提示。

## 已提供的交互

- 12 只虚构样本，两市筛选、名称/代码/行业/概念关键词搜索、涨幅降序/默认排序。
- 本次会话自选添加、移除和空结果状态；切股更新资料、图表和委托表单。
- 日 K / 小时 K、MA5 / MA20 开关、悬停十字光标、左右方向键逐根查看。世界日 288 为示例当前日，对应第 1 赛季第 39 日；当前第 2 小时未完成，日 K 仅含截至世界日 287 的完成日线。
- 三类委托表单、买卖方向、价格微调、股数快捷填写、分批计划结束小时；输入与示例资源提示；提交按钮只打开委托预览。
- 持仓关联选股、公司资料、资讯全文与相关股票导航。原生 dialog 支持 Escape、背景关闭和焦点约束。

## 实现边界

`apps/web/src/market-demo.ts` 是仅用于界面开发的固定 fixture，不是市场生成器，也不是未来核心的冻结公开接口。示例不会随系统时间、刷新或操作生成新成交；不得用它证明资金守恒、市场稳定性、预热、双市场机制或玩法有效性。

本次没有实现交易提交、撮合、账本、时钟推进、开局预热、游戏导入导出、耐久存档或赛季结算。不显示虚假的“成交成功”或“游戏已保存”。外观设置保存在本机，自选只保留于当前会话，两者均不会改变行情。

真实交易功能须在对应阶段接入 `packages/sim-core`，用已冻结公开投影替换 fixture；SVG 为 UI 展示组件，不代表正式 Canvas 图表依赖选型或 P0 图表性能试验已通过。
