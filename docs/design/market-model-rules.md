# 模型规则与初始参数

交易/内容规则版本 0.3.1，2026-10-01；初始化候选版本 world-v2-style-cash、NPC报价候选版本 npc-quote-v2-target-gap，2026-10-02，待P2独立验证。[玩法模型](./gameplay-market-model.md) 的规则附录。历史P0/P1通过结论描述原 world-v1 初始化及原报价，不因此改写。本版补齐双市场profile、确定性数值/快照/初始化与实验合同；以下“必须”是实现合同，参数表是可校准初值。没有标注的现实制度不自动补入游戏。补充合同见[市场特色](market-identities.md)、[工程基线](engineering-baseline.md)。

## 1. 状态、单位与作用域

| 对象 | 必要状态 | 谁可读取 |
|---|---|---|
| 世界 | 连续世界日期、批次、经济状态、行业状态、未公开事件、随机流和规则版本 | 核心；公开部分进入公共快照 |
| 公司 | 行业、概念暴露、总/流通股数、实际经营指数、历史公开简报 | 实际经营仅世界层；公开简报所有参与者可见 |
| 市场 | 可售规则、合法价格区间、最近成交和上日收盘 | 所有参与者 |
| 账户 | 现金、冻结资源、股份批次、观察尺度、持续目标向量/股数、复核时点、预测误差和风格 | 账户自身；其他人只见公开统计 |
| 委托 | 所有者、股票、方向、限价、原始/剩余数量、有效批次、到期点、计划来源 | 所有者与撮合核心；公开统计做聚合 |
| 事件 | 公布时点、公开预期、真实结果、作用渠道、覆盖期间、版本和应用标记 | 按公开时点隔离 |
| 服务账户 | 已收手续费与下次分配日期 | 总账审计；不参与股票交易 |
| 生涯记录 | 玩家进入日期、原始本金、赛季记录、累计指标、里程碑与结束状态 | 玩家与存档；不反馈到 NPC 或世界生成 |

现金以BigInt分为整数，价格以每股分为Number整数，股份为Number整数；两个市场最小成交单位均为 1 股，最小价格步长均为 0.01 虚构货币。这是游戏简化。价格≤100,000,000分、每股总股数≤8,000,000,000、聚合金额≤2×10^20分，价格×股份与比例中间量先转BigInt。模型状态为Q9定点，费用及订单舍入依第5/6节；固定数学、随机与编码依工程基线，禁止平台Math.log/exp或Math.random决定行情。

时间为 `(连续世界日, 0..15 批次)`；世界日从 0 连续增长，批次 0/4/8/12 前分别开始一个小时窗口。世界前 250 日用于预热，世界日 250 对应玩家第 1 日。事件可以在任意批次的公开窗口发布；相同时间按事件稳定 ID 排序。解锁、报告、费用周期、NPC 复核、指标窗口和随机键均使用世界时钟，不按赛季重置。

交易核心不得向参与者函数提供隐藏经营、未来分支或其他账户的私有状态。建议参与者入口只接收 `公开快照、自身账户、风格参数、该主体随机状态`。图表和信息面板也使用同一公开快照。

## 2. 初始化与配额

公司行业、大小盘和概念配额采用 [主设计第三节](./gameplay-market-model.md)。分配概念时从合法业务暴露图中选择，若种子无法满足所有配额，重新生成分配方案；不能静默超出两标签或破坏业务关系。

概念允许行业集合：储能革新＝能源/工业/基础设施；算能扩建＝数字/基础设施/能源；自主工艺＝工业/数字/健康；城市更新＝基础设施/工业/消费；自动作业＝工业/数字/消费；循环资源＝能源/工业/消费；长寿技术＝健康/消费/数字；跨境通道＝工业/能源/消费。每条关联还需生成对应的业务说明，不能仅靠行业允许就宣称相关。每次分配最多重试 64 次，仍不可满足则显式报告生成配置失败。单概念暴露为 0.3–1.0，双概念先抽取后按总和不超过 1 归一化。

初值：大盘总市值 100–400 亿，中盘 20–100 亿，小盘 2–20 亿；边界用半开区间消除重叠。流通比例 25%–70%，开局报价 5–100 元。先确定股份数与初始价格，再回算实际市值并检验所属区间；不要同时保存互相矛盾的市值和股数。

流通股份 90% 分给该市场本地资金，10% 分给两个跨市场配置账户；非流通部分归固定创始持有人，首版不交易。每只股票分配数量之和必须精确等于流通股份，余股按稳定的最大余数分配。

| 本地风格 | 每市场账户数 | 甲本地股份份额 | 乙本地股份份额 |
|---|---:|---:|---:|
| 价值 | 3 | 28% | 40% |
| 趋势 | 2 | 18% | 16% |
| 主题 | 2 | 20% | 12% |
| 库存再平衡 | 4 | 26% | 26% |
| 噪声 | 1 | 8% | 6% |
| 合计 | 12 | 100% | 100% |

各风格内股份分给独立钱包，再对初始各股持仓作小幅受约束扰动以产生不同库存需求；角色分工见 4.4。初始化协议保存在 world.generationVersion 并参与 configHash。历史 world-v1 每个NPC现金为初始股票值25%，使普通钱包起始持股比例80%；P2保留两种子诊断出现大面积减仓缺口，见[合同核对/阻塞报告](../../packages/sim-core/p2-contract-diagnosis.md)。候选 world-v2-style-cash 仅新建时令普通钱包现金=floor(初始股票值×(1−f)/f)，f为原风格基础持股比例：价值/跨市 .70、趋势/主题 .60、噪声 .55；跨市仍只有一份钱包。库存为独立股数目标，现金继续floor(初始股票值/4)，90%是风险上限，不能替代为普通持股目标。所有初始股份已过持有期。玩家禀赋仍默认100万、范围10–1,000万，250日预热后一次加入。

候选保留全部26角色、逐股股份与±5%分配扰动、原风格行为参数、报价/保护/费用及预登记门槛；普通风格初始现金和“现金+股票”总资产份额明确变化，不再将上表称总资产份额。固定费用回流权重取新建当时实际现金，此后不变。完整旧/新逐钱包数值与原失败种子见[初始化候选样本](../../tests/scenarios/p0/initialization-candidate.json)。旧世界恢复仍为world-v1，绝不转换初值或补差额；本候选不是存档迁移。先同原两种子重新真实预热250+5诊断，再决定是否运行全部100+10；不叠加第二调参，不保证候选通过，不改90%×80%硬门槛。

开局前预热 250 个交易日，玩家从预热结束后进入。预热的价格、账户和事件全部来自同一模型，保留作为玩家可看的过去历史；这提供 120 日变化和 MA200 所需的完整时间窗口，不保证所有窗口都有真实成交。NPC 预算与目标记忆取预热后的真实状态；玩家本金随后一次性加入，不能每天或每季重发。初始化库存目标、日历相位与价格保护状态不在正式开局重置。

预热早期信号不足时按 4.1 使用中性先验，达到窗口长度后才启用对应历史项；图表按 8.2 显示不可用或无成交标记。预热在 Worker 中执行并可缓存同版本、同种子、同初始化参数的完整世界快照；不得只缓存 K 线而重新发放 NPC 钱包，也不得用预写波浪代替预热。启动耗时单独验收。

## 3. 世界与公司经营

此层生成可解释但不保证获利的环境，不直接生成成交价格。下列过程为首版选定的简化生成器。

### 3.1 日级宏观与行业状态

三个宏观因子为需求、融资环境、风险偏好，均在 `[-1,1]`。每天开盘公开一次新值：

```text
X_next = clip(0.96 * X + 0.04 * regimeMean + 0.04 * z + publishedShock, -1, 1)
行业状态 U_next = clip(0.94 * U + 0.06 * z_sector + industryShock, -1, 1)
```

`z` 为独立、固定随机键上的有界正态近似：12个U[0,1)之和减6，截断在 ±3，不是精确正态采样；算法与槽号以工程基线rng-v1为准。经济阶段驻留时间在 20–60 日之间均匀抽取；阶段名称对玩家不直接揭示，玩家看到公开因子。到期才按下表转移，不按固定顺序轮流牛熊。这是游戏环境的简化尺度，不是技术波浪计数；赛季末不强制转换阶段。

| 阶段 | 因子均值：需求/融资/风险偏好 | 转到扩张/过热/收缩/修复 |
|---|---|---|
| 扩张 | 0.5 / 0.2 / 0.4 | 0 / .45 / .20 / .35 |
| 过热 | 0.7 / −0.3 / 0.7 | .25 / 0 / .55 / .20 |
| 收缩 | −0.6 / −0.4 / −0.7 | .10 / .05 / 0 / .85 |
| 修复 | 0.1 / 0.5 / 0 | .60 / .10 / .30 / 0 |

行业状态也向公众公开为带区间的景气指标；参与者只能读公开值，不能读取扰动的未来抽样。宏观因子同向变化不等于所有公司同向变化，公司暴露可以不同。

### 3.2 公司经营与公开估值基准

经营指数 `E` 起点为100。每世界日的增长在该日结束累积，下一开盘公告/报告前提交；报告包含截至前一世界日的经营。瞬时事件在对应公开准备应用一次。真实日变化：

```text
g = clip(mu_i + 0.0005 * dot(b_i, X_public)
         + 0.0005 * U_market_sector + epsilon_i
         + 0.0002 * 负债敏感度 * 本市场已生效融资环境, -0.003, 0.003)
log(E_next) = log(E) + g + 已实现的公司事件冲击
```

`mu_i` 初值在 −0.0002 至 0.0004；暴露向量绝对值之和不超过 1，风险偏好不直接提高真实经营，只通过交易层起作用。`epsilon_i` 标准差 0.0008、截断 ±3 倍。`E` 在 5–2,000 之间截断；事件冲击单次绝对对数变化不超过 0.20。这些数值是平衡旋钮，不是现实收益统计。

每20世界日公开一次当前E，每公司phase=(市场内稳定序号−1) mod20，开盘worldDay mod20=phase时发布；初始E=100为共同公开基期。玩家与NPC共同知道最近两次已公开E、间隔日数、业务暴露和公开事件。公开预测基准：

```text
g_public = clip((两次公开 E 的对数变化 − 期间公开可量化的已实现事件贡献) / 间隔日数
                + 0.0005 * 公开需求暴露项, -0.003, 0.003)
log(E_forecast) = log(E_last_report)
                 + g_public * (距上次报告日数 + 20)
                 + 尚未被该报告覆盖的公开事件预期修正
V_public = P_initial * E_forecast / 100
           * exp(0.20 * 公开负债敏感度 * 共享公开融资因子
                 + durationK[market] * durationSensitivity * rateOutlook)
```

这是一种公开预测模型，不是真实价值，界面称“经营预期参考”，附预测区间。报告基期使用初始化 E=100，不因预热结束而重置。只有一份简报时，增长估计用零作为历史部分，保留公开需求项。

事件修正按事件 ID 和覆盖期间保存：公布结果替换该 ID 的旧预期；后续报告已包含实际影响时移除已覆盖部分。持续作用事件分别保存报告间已实现贡献和预测窗口内剩余贡献，不能把未来部分也一起删去。计算持续增长率时先剔除公开可量化的已实现事件贡献，避免一次性增长在报告后又被外推 20 日。无法从公开资料辨认的变化仍会带来预测误差，不能读取隐藏账来补齐。经营落地、公告和新闻解读不能让同一收益重复计算三遍。

## 4. 观点、主题与目标持仓

### 4.1 个人预测和价格信号

账户预期估值：`V_a,i = V_public * exp(bias_a,i + beliefNoise_a,i)`。固定偏差初值在 ±0.12；观点噪声按 `eta_next = clip(0.9*eta + sigma*z, -.10, .10)` 延续，每批更新一次，不能每次点开界面重抽。噪声强度见参数表。

共同信号只使用上一批及更早成交。令 b 为最近已完成批次，d 为最近已完成交易日；P_b 为该批结束时最新真实成交的参考价，C_d 为该日已完成收盘参考价。日级信号在新日线完成前不随未完成日线更新：

```text
F = clip(log(V_a,i / P_last) / 0.25, -1, 1)
T_short = 0.6 * clip(log(P_b / P_(b-4)) / 0.08, -1, 1)
        + 0.4 * clip(log(P_b / P_(b-16)) / 0.15, -1, 1)
T_swing = 0.6 * clip(log(C_d / C_(d-5)) / 0.12, -1, 1)
        + 0.4 * clip(log(C_d / C_(d-20)) / 0.25, -1, 1)
T_long = 0.6 * clip(log(C_d / C_(d-60)) / 0.35, -1, 1)
       + 0.4 * clip(log(C_d / C_(d-120)) / 0.50, -1, 1)
Risk = clip(过去20日的日收益标准差 / 0.06, 0, 1)
```

每项动量必须同时拥有两个端点；例如 120 日变化需要 121 个已完成日收盘参考。历史不足的单项贡献为 0，不把剩余项放大，也不复制最早价格补足历史。Risk 使用 20 个已完成日收益，样本标准差分母为 19；不足 21 个日收盘参考时用固定先验 0.20。这些先验只用于预热/历史不足的 NPC 决策，不能在 UI 冒充已计算出的指标。

零成交窗口延续最近实际价并保留无成交标记，首笔成交前初始发行参考价只用于启动估值和报价，历史信号视为不可用。图表上的形态识别还须满足成交样本要求，不能把多根零成交平线解释为成功构筑支撑。所有公式中的 T 按 4.4 选为该账户的 T_short、T_swing 或 T_long；这些常数是游戏初值，不是艾略特比例或现实统计校准。

### 4.2 主题注意力

每个概念维护公开消息关注 A、跨成员扩散 B、持续关注 L：

```text
A_next = clip(A * exp(-1/64) + 本批公开关注增量, 0, 1)
B = 同时满足“过去一小时正收益、成交量高于历史同窗均值”的成员比例
    （不足3家符合时 B=0；每成员权重相同且不超过1/3）
L_next = 0.98 * L + 0.02 * H_previous
H = clip(0.5*A + 0.3*B + 0.2*L, 0, 1)
```

历史同窗均值使用此前 20 日同一个游戏小时，不能包括当前未完成小时。关注增量由事件模板给出，通常 0.10–0.35；负面事件同样可以提高关注。

每个账户对该主题的方向判断 `Outlook` 来自已经公开的预期修正之和除以 0.10，再加自身持续观点误差，截断到 `[-1,1]`。已归档事件的方向影响在 5 日内指数衰减。公司主题信号为 `H_i = sum(业务暴露 * H * Outlook)`；同股概念暴露和不超过 1。

公开拥挤估计 `Crowding` 取主题成员以下指标的均值：`clip(0.5*20日平均换手率/0.10 + 0.5*max(0,log(P/V_public))/0.30,0,1)`。它是估计，不泄露 NPC 持仓。

“沉寂、扩散、拥挤、退潮”仅用于解释与诊断这些连续量，不再额外抽签决定涨跌，也不再额外乘一次价格系数。主题与趋势买入倾向乘 `(1−0.7*Crowding)`，降低极度拥挤时的无边界追随。

### 4.3 目标权重

普通账户的目标评分：

```text
S = alpha*fundamentalMultiplier[market]*F + beta*T_a
    + gamma*themeMultiplier[market]*H_i - 0.30*Risk + scoreNoise
原始权重 = baselineWeight * exp(S / temperature)
原始股票比例 = 归一化原始权重 * 目标持股比例
原始完整目标 x_raw = 风险裁切后的各股票占净值比例 + 剩余现金比例
```

`baselineWeight` 为世界初始化时的持股市值占比，不在玩家入场或续季时改写；每股至少给非零小权重以允许以后重新发现机会。本地账户只能交易本市场，跨市场账户可交易全部股票。原始股票比例按单股净值 15%、行业净值 35% 上限做迭代裁切再分配；没有剩余合格资产可分配的预算留现金。x_raw 所有分量非负且总和为 1；跨市场账户对相同行业合并计限额。已被价格变化推过上限的实际持仓不会神奇地按参考价强平，目标只产生受约束卖单。原始完整目标再按 4.4 转为持续目标，不能每批跳过调整速度直接使用。

| 风格 | alpha/beta/gamma | 温度 | 基础持股比例 | 观点噪声 sigma | 每小时个股数量上限：报价容量基准占比 |
|---|---|---:|---:|---:|---:|
| 价值 | .90 / .05 / .05 | 0.8 | 70% | .002 | 4% |
| 趋势 | .15 / .70 / .15 | 0.6 | 60% | .004 | 10% |
| 主题 | .15 / .15 / .70 | 0.6 | 60% | .005 | 10% |
| 噪声 | .20 / .10 / .10 | 1.0 | 55% | .008 | 6% |
| 跨市场配置 | .75 / .15 / .10 | 1.0 | 70% | .002 | 4% |

`scoreNoise` 使用同一账户股票的持续噪声，价值/跨市场倍率 1，趋势/主题 2，噪声账户 5。普通账户持股比例加 `0.10*公开风险偏好` 后裁到 35%–85%。跨市场配置的 baselineWeight 再乘该市场公开行业景气加权得到的 `exp(0.25*景气)`，不读另一市场未来结果。

库存再平衡账户采用单独的、以股数计的目标：开局股数乘 `1+zeta`，`zeta` 每日按 `0.8*zeta+0.01*z` 更新并截断 ±0.10；目标偏离驱动买卖，报价由公开预期及5.2的本人剩余需求决定。库存账户初值持仓风险上限为净值 90%、单股 15%、行业 35%，越界只允许减少相应风险，不能新增越界买单。其观点 sigma=.002，每小时数量上限为报价容量基准的 10%。

### 4.4 观察尺度、复核频率与持续目标

账户数与各风格初始股份分配份额保持不变，使用下表拆分行为角色；world-v2-style-cash现金及总资产份额变化已在第2节明确。风格参数沿用 4.3；lambda 表示一次常规复核吸收原始目标变化的比例，不是持仓收益率或固定持有期限。

|---|---|---|---|---:|
| 经营修复价值 | 每市场 1 | T_swing | 每日开盘 | 0.25 |
| 经营配置价值 | 每市场 1 | T_long | 每 5 世界日开盘 | 0.20 |
| 长期价值 | 每市场 1 | T_long | 每 20 世界日开盘 | 0.35 |
| 短线趋势 | 每市场 1 | T_short | 每小时开始 | 0.75 |
| 波段趋势 | 每市场 1 | T_swing | 每日开盘 | 0.25 |
| 事件主题 | 每市场 1 | T_short | 每小时开始 | 0.60 |
| 主题配置 | 每市场 1 | T_swing | 每日开盘 | 0.25 |
| 噪声 | 每市场 1 | T_short | 每小时开始 | 1.00 |

周期为 k 日的常规复核在 worldDay mod k=0 且批次为 0 时触发；小时复核在批次 0/4/8/12。日级信号取此前已完成日线。跨越玩家入场或赛季边界时相位不变。

普通账户在复核时更新 x_next=(1-lambda)*x_previous+lambda*x_raw，其中 x 是包含现金的完整目标比例。两个向量均受同一风险上限约束，因此合成后仍须非负、总和为 1 且不过限。世界初始化时，x_previous 取实际组合比例经同样裁切后的结果，超出部分转为目标现金；实际库存不被改写。每次复核以当时上批净值 N 和 P_last 固定目标股数 floor(N*x_next[i]/P_last)，保存计算快照版本。两次复核之间持续执行剩余缺口，不因每批重报价、点击 UI 或股价浮动而重新计算整套目标股数。

公开事件模板可预先标记“重大”；普通报告只有公开经营预期参考相对上一公开版本绝对变化至少 5% 时才触发同级提前复核。覆盖该账户已有持仓/合法业务暴露的重大信息触发额外一次复核，lambda_event=max(lambda,0.5)，不改变下次常规排程；常规与事件同批触发只复核一次并取较大比例。同一公开快照不得重复更新。该门槛也是初值，不依据玩家盈亏、浪数或赛季终点设置。

每批对实际仓位检查风险上限。越界时撤销会增加越界风险的买单，只下调相关目标股数并尝试有资源支持的减仓；不能利用这次紧急处理新增其他买入，不能受慢速 lambda 阻碍而继续增加越界仓位。未能卖出仍保留真实风险，不伪造强平。

同批顺序固定为先完成到期的常规/重大信息目标复核，再施加风险减仓约束，最后据目标缺口生成订单；正常复核不能覆盖本批风险限制。风险处理本身不额外更新持续观点噪声或随机流。

所有账户每批仍使用当前公开信息更新愿付/愿售报价，即使慢速目标股数尚未复核；重大新闻后不得保留必可吃到的过期报价。事件与风险处理均不重置本小时已用容量。持有期和可用现金限制对所有角色相同，没有“长期账户无条件托底”。

## 5. 从目标到有限委托

### 5.1 数量和真实资源

普通账户目标股数使用 4.4 上次复核保存的结果；库存账户用其股数目标。NPC 有符号剩余需求=`目标股数−当前总持股−有效买单剩余量＋有效卖单剩余量`；当前持股已经包含成交，不能再减一次累计成交。目标反向时先撤原单再计算。玩家总量计划则用 `总计划股数−累计成交股数` 计算剩余量，两种语义分开。

每个账户每只股票的本小时绝对成交量上限，在小时开始根据报价容量基准计算并固定：`L=0.5*过去20日ADV+0.5*(0.01*流通股份)`。历史不足时 ADV 用已有数据，零历史时用括号内常态先验。该基准只设定主体最多愿意提交多少数量；最后仍取目标缺口、小时余量、真实可售股份或现金预算的最小值。常态先验不是盘口恢复量，不生成任何订单、现金或股份。

保留常态先验是为了避免“成交减少→未来允许的申报量更小→成交进一步减少”的机械反馈。每股 14 个可参与 NPC 的上限之和为每小时 `1.06*L`，日成交双侧理论上界约 `2.12*L`，实际远低于此且必须验证。这给报价留出余量，不是成交量目标。

每批计划量为 `ceil(本小时剩余计划量 / 本小时剩余批数)`，受小时剩余上限约束；卖方还受可售量约束。买单先生成保护价并计算总资金需求，再对账户**全部股票、两个市场**统一处理：

```text
缩放率 s = min(1, 本批可用现金 / 所有买单的保护价含费成本上界)
每条买单量 = floor(原计划量*s)
```

缩放取整后必须重新计算全部子单的含费冻结金额；逐股手续费向上取整意味着费用不严格同比缩放，仍可能差一分。若超预算，按目标评分从低到高、同分按股票ID和档位的固定顺序减少股数，每次重新验算，直到不超现金。保留闲置现金，无需强行分光。手续费成本上界对每条子单向上取整后再相加，确保实际汇总费用不超预留。所有卖单同样在撮合前冻结股份。预计本批卖出款不计入现金预算，所得资金下一批才可重新下单，避免股票遍历顺序造成优势。

### 5.2 报价

```text
R = V_a,i * exp(kT*T_a + kH*themeQuoteMultiplier[market]*H_i)
```

价值/库存/噪声/跨市场的 `kT/kH=.01/.01`，趋势 `.06/.02`，主题 `.02/.10`。拥挤时对趋势与主题买入的附加项按 4.2 衰减；它影响愿付价格，不直接改变成交价。

P2第1轮独立验收确认原合同的目标与报价不相容：本人有增持缺口的低愿付买者与有减持缺口的高愿售卖者可以长期互相拒绝，实际52,284条报价未发现实现偏差。单一候选 `npc-quote-v2-target-gap` 保持上述 R 与评分、持续目标和全部数量/资源规则，仅将本人剩余需求转为有界保留价格：

```text
g = 5.1的有符号剩余需求（股），在本批风险限制之后计算
I = 本人该股初始化股数（股，固定且至少1，不随成交补回）
uQ = clip(BigInt(g)*Q9/BigInt(I), -120000000, 120000000)
R_exec = R * exp(uQ/Q9)
```

Q9除法按确定性整数协议向零截断；最大对数响应±0.12是本候选唯一新增行为初值，约为R的0.8869–1.1275倍。增持缺口提高愿付、超额库存降低愿售；g=0仍不生成委托。实际成交改变持股后偏离随之收敛，不重算目标、不刷新小时预算、不读取他人持仓或隐藏结果。全部买单仍按新价格做跨股/跨市含费统一缩量，卖单仍以真实可售股冻结；不足资源、风险越界、无交叉或保护阻断仍可零成交。

新世界显式保存 `world.npcQuoteVersion` 并纳入configHash与预设/实验manifest。缺字段的旧world-v1及world-v2-style-cash快照有效版本均为 `npc-quote-v1`，仍取 `R_exec=R`；恢复、查询和导出不得补字段或转换钱包，旧规范字节及后续报价保持。显式v1也合法，未知值拒绝。交易/内容0.3.1、schema1、math/rng均不变，报价行为由该独立版本标识。baseline与未来complete从创建采用同一报价合同；报价改变后必须重新初始化并完整预热，不混用旧预热。当前候选未证明经济达标，依据及两组固定反例见[NPC报价候选](../../tests/scenarios/p0/npc-quote-candidate.json)和[第1轮失败报告](../verification/p2-independent-round-1.md)，90%×80%硬线不改。

计划量按 20%/30%/50% 生成最多三档，同方向价格：买为 `R_exec、R_exec*(1−w)、R_exec*(1−3w)`；卖为 `R_exec、R_exec*(1+w)、R_exec*(1+3w)`。`w=0.002+0.008*Risk`，向合法价格步长取整（买向下、卖向上）。少于三股时按最大余数分配，零数量档不发单。

保存账户真实愿付/愿售的原始限价并据此冻结资源；市场价格保护限制实际清算价，不删除区间外意向。卖方最低接受价高于上界时，当批无法成交，不能把它强行压低。区间外但有资金支撑的交叉需求用于第 6.2 节重开判断；不把这些报价画成成交。

NPC 子单仅本批有效；每批到期释放未用资源，然后依据**持续目标缺口、实际库存、实际现金及本小时剩余预算**再提交。重报委托不是把成交过的库存补回来。账户不能同时在同股提交双向委托。

### 5.3 玩家订单

| 类型 | 规则 |
|---|---|
| 受保护即时单 | 玩家指定数量与最差接受价，下一可执行批参与；本批剩余撤销 |
| 限价日单 | 下一可执行批开始参与，剩余保留至当日最后一批清算后；可撤单 |
| 分批计划 | 明确总股数、保护价与终止小时；按剩余股数/剩余批次生成即时子单，未成交量滚入计划剩余量，结束时停止 |

买入计划创建时冻结 `剩余股数*保护价 + ceil(剩余最坏金额*费率) + max(0,K−1)分`，其中 K 为剩余数量和最多剩余执行批数中的较小者，用于覆盖逐批向上取整费用。日单也按到期前最多批数预留，受保护即时单 K=1；多个独立订单分别预留可保守多冻，不能少冻。卖出计划冻结当前可售股份；即使部分资源暂未发单也不能另用。按实际成本扣账后，用同一公式重算剩余预留并释放差额。新计划不预支未来卖出款，也不提前占用明天才解锁的股份。

同账户、同股票、同批只允许一个方向；切换方向先成功撤销反向单/计划。多个同方向同价委托在清算分配时按账户聚合。玩家资金不足、可售不足、限价不是正整数 tick 或超出数值安全范围时明确拒绝，不能静默修改数量。可以申报超出当前价格保护区间的限价，但界面说明实际清算受市场区间约束；保留限价也不代表承诺未来成交。受保护即时单不是保证成交的无条件市价单。

预览使用上批公开供需与历史波动给出估计区间，不试算下一批真实隐藏委托；重复预览不改变随机状态、深度、预算或优先级。

## 6. 每批统一清算

### 6.1 顺序

1. 解锁到期股份；处理到期单及已提交撤单；每日开盘先执行到期费用分配。
2. 推进世界，公开该批事件和日级资料，生成公共快照版本。
3. 若达到玩家指定决策点则暂停。此时没有该批成交；玩家可以提交/撤改。
4. 执行计划与 NPC 依据同一公共快照生成订单；跨股统一检验与冻结资源。
5. 各股独立选清算价并分配数量；只使用本批冻结资源。
6. 一次性提交所有成交与费用；卖出所得现金和乙市场新股份从下一批可用。
7. 记录结果、更新已公开交易统计与小时/日 K，保留诊断日志；日终完成到期单释放及里程碑统计。如到赛季末则记录成绩并暂停，否则推进至下一批。

相同有效指令集下，股票循环顺序、UI 刷新次数和暂停开关不得改变成交。撤单只撤未成交部分，已完成清算不能回滚。

### 6.2 合法价格区间

甲正常日：`[ceil(上日收盘*0.90), floor(上日收盘*1.10)]`，以价格 tick 为单位；乙常态批次：最近实际成交价的 ±8%。所有下界至少为 1 tick，首个预热批次使用初始价格。参考价与最新实际成交价分开记录，零成交不制造新收盘。

为避免新区间永远无法发现价格，每批额外用同一组有资源支撑的原始委托计算一次无市场价格带的指示清算（仍受各单限价和正价格约束），只用于识别保护区间是否阻断了真实交叉需求。其结果不计成交、成交量或持仓；不向玩家提供下一批的隐藏订单试算。

- **乙重开**：若合法区间Q=0，而无价格带Q>0、指示价在区间外，结算后公开下一批±16%；继续受阻依次±32%、±64%，仍受阻时下一批一次特别竞价。扩带参考保持最近真实成交，不按指示价移动。任一真实成交后下批恢复以新成交价为参考的±8%；无交叉需求（包括空订单）不扩带，下一批复位±8%。特别竞价若无成交亦复位±8%，以后须重新积累受阻证据。特别竞价仍受各单保护价、正tick和MAX_PRICE限制。
- **甲重开**：日内仍保持正常边界，保留隔夜与跌停无法退出的体验。若连续两整日零成交，且两日最后一批均存在上述区间外交叉需求，则第二日收盘公开宣布下一日开盘进行一次无市场价格带的特别竞价。只有实际成交后，才以特别竞价成交价作为该日余下批次的 ±10% 参考。特别竞价无成交则该股保持重开状态，之后每日开盘重新尝试，日内不提供虚假的正常撮合。

重开公告在可操作窗口发出；到重开批次所有账户重新用当时信息和资源报单，旧的指示价不保证成交。特别竞价是一项明确的虚构交易规则，不宣称复制现实涨跌停或熔断制度。

冻结状态表：乙normal8→expanded16→expanded32→expanded64→special，转换仅由本批零成交且无带有真实交叉触发；甲normal→一整日零成交且末批受阻count1→连续第二符合日收盘announced→次日开盘special。任何甲日有真实成交或末批不受阻均将资格计数归零。甲special成交则当日余批按成交价±10%；special无成交进入reopenPending，日内不清算，之后每日开盘重新报单尝试，不能用历史指示价补成交。所有区间裁到[1,MAX_PRICE]。边界能成交时按真实成交处理，不能误判保护阻断。反例见 `tests/scenarios/p0/protection-cases.json`，A13/A14保留原两日/扩带语义并补足无交叉复位。

### 6.3 清算价

对合法整数价格 p：

```text
D(p) = 买限价 >= p 的有效股数之和
S(p) = 卖限价 <= p 的有效股数之和
Q(p) = min(D(p), S(p))
```

依次选择：最大 Q → 最小 `abs(D−S)` → 最近于上批之前最近实际成交价 → 仍相同则选较低价格。最后一个方向性取舍固定写入规则，避免依赖遍历顺序；可在后续调参中比较其他平局规则，但更改必须提升规则版本。

候选集合包含所有有效限价、每个限价 ±1 tick、合法区间边界，以及裁到区间内的参考价，去重并过滤非法价格。这样覆盖供需阶梯各区间的端点与距参考价最近的位置。**只检查挂单限价会漏掉两个限价之间更平衡的清算价。**

最大 Q=0 时不成交，不创建新清算价；“中间价”只能作为参考信息，不能伪造成交。

### 6.4 数量分配与收费

买侧按限价由高到低，卖侧按限价由低到高，各自分配 Q 股。同价先按账户合计数量；当该价位剩余可分量不足时按数量比例分配：先向下取整，再按小数余数由大到小发剩余股；同余数以 `(世界种子, 批次, 股票, 方向, 价格, 账户ID)` 的稳定散列顺序决胜。委托 ID 和拆单次数不参与平局规则。

分到某账户的数量再按该账户内部提交顺序记入其订单，只影响订单回执，不改变账户总获配量和收费。两侧获配总和必须相同；由于同账户同股单向，不会形成自成交。

每批所有成交均按 p*。按账户×股票×批次×方向汇总成交金额，手续费=`ceil(金额分*0.0005)`。买方扣成交额与买费，卖方收成交额减卖费，两侧费用均进入服务账户。没有最低佣金，没有额外价差或冲击费，拆单不改变汇总舍入。

分摊费用时先把同一计划的当批子单合并，与独立订单一起作为归属项：每项先取其实际成交金额对应费用的整数下界，再按小数余数最大法分配账户汇总费用剩余的分；同余数按稳定归属 ID。各项之和精确等于账户当批费用，且单项不超过其独立向上取整费用，扣账与释放预留仅发生一次。

市场甲新股份标记下一交易日开盘可售；市场乙新股份标记下一批可售。买方现金不会因为结算价优于保护价而被多扣，剩余冻结按订单/计划时效保留或释放。

## 7. 事件结构与去重

每个事件保存 `eventId、渠道、目标与业务权重、公开时点、事前预期均值与范围、隐藏结果、当前阶段、已应用效果、覆盖报告期、关联链ID`。

选用三类具体机制：

- **经营结果**：结果按既有公开预期附近的有界分布生成，代表8模板/2链的具体均值、sigma、范围、渠道单位和抽样键冻结在[event-v1合同](event-content-contract.md)及 representative-events.json；按业务权重改变 E 或未来一段增长，预期和结果以相同 ID 替换。先后公布的新闻不能反复累计同一结果。P4其余模板须按同schema登记参数，不得在代表模板实现时另设隐含默认值。
- **融资/需求环境**：改变宏观或行业因子，公开后由业务暴露传导；不另为所有股票直接加跌幅。
- **信息与注意力**：预告、传闻、解读只改变公开观点区间、可靠性与关注 A；未经兑现不直接修改实际 E。核实后落地真实效果或撤销预期。

24 个模板分为经营 10、行业 6、宏观 4、信息/注意力 4；其中选择 6 组组成分支链。突发重要事件每日候选概率初值为公司 0.35、行业 0.12、宏观 0.03；每类至多一个新起点，已有链按排程继续。公开简报独立错峰，不计入这些概率。

同公司同时最多一条未解决重大事件链，同概念最多两条；冲突候选延后或改选合法对象。影响对象由世界状态和模板条件决定，不读取玩家持仓。选股持仓只能影响通知筛选。

未兑现公开预期的残留期最多 20 日，到期必须更新、核实或标记失效并衰减；不能无限叠加利好。所有分支抽样有固定键，读档、预览、增加订单不能改变抽样槽位。

有效截止为公开时点加20世界日的同一批，公开准备时先处理截止版本：若当批有更新/核实，用更高revision替换；否则立即将该版本active贡献归0，归档方向只用于5日衰减的Outlook。更新/结果替换同effect ID，不相加；旧revision到期不得移除更高revision。长链通过≤20日一次公开更新持续，结果可跨季。行业状态按市场×行业，rateOutlook/effectiveFinancing来源及profile参数以[市场特色](market-identities.md)为准；政策汇总仅展示，避免同消息同时改变因子、经营贡献与折现三次。

## 8. 资金循环、价格记录和结局

### 8.1 持续资金循环

交易现金守恒范围包括所有 NPC、玩家和服务账户。每 20 日开盘，服务账户将截至此前收盘的余额按开局 NPC 现金份额分配，分配总额不超过余额；份额不随亏损、排名、股价或玩家盈利变化。整分余数按稳定最大余数分配。玩家不直接获得该分配，没有任何股票库存随之重置。

首版没有股息、发行、回购和额外居民注资。因此现金总额在初始化后恒定；浮动市值可以变化，不要求市值守恒。没有成交不是系统错误，持续全市场枯竭则是模型验收失败，要调整行为/初始化并重跑，而非临时免费补资金。

### 8.2 K 线、指标与技术形态

每小时 K 使用四个批次实际成交：首个成交为 O、最后成交为 C、成交价最大/最小为 H/L，V 为该小时每次清算 Q 的总和。日 K 从该日实际成交按同一规则聚合。零成交批不制造高低点；整小时/整日零成交则显示最近成交价的平线、V=0并标注无成交，另保留最近真实成交时点。未完成小时/交易日明确标记进行中，图表不能读取未来批次。

日线提供 MA5/20/60/200，小时线提供 MA5/20；MA_n 为最近 n 个已完成同尺度收盘参考的算术均值。少于 n 个窗口时显示不可用，无成交参考必须有标记，不能当成 n 次独立成交。NPC 日级信号和技术诊断不使用未完成日线；小时诊断只在小时结束后确认，最早下一批可据此行动。

保留完整日线及至少最近 120 日小时线；任何归档都须保留当前指标窗口、仍有效形态的确认记录和其参考水平，不能改变后续信号。长期手工标注只引用当时可见历史。首版不实现自动艾略特计数、斐波那契必达目标或形态触发价格加成；诊断识别口径在验证方案 4.1 定义，标签不成为隐藏经营状态。

### 8.3 赛季、生涯和结束

令 g 为玩家交易日，从 1 开始；赛季编号 s=floor((g-1)/250)+1，季内日序为 ((g-1) mod 250)+1。250 日预热不计入 g；60 日只是体验原型的测试范围。正式游戏第 250、500、750、1,000 日收盘等时点记录赛季成绩，不强制终止生涯，不承诺这些时点正好完成一个技术形态。

每个赛季末按如下顺序处理：最后一批清算入账 → 日单/当日到期计划释放 → 完成日线与当日里程碑、资本耗尽统计 → 固定成绩快照并保存 → 暂停展示。成绩键为生涯 ID 与赛季编号，重复展示、保存或恢复不能再次结算。继续后进入下一世界日的正常开盘顺序；仅看结算页不提前解锁 T+1 股份。

跨季保存全部市场状态，包括 NPC 持续目标与复核相位、事件链、随机流、价格保护与重开状态、费用周期、历史指标、玩家现金、股份解锁时间及未到期计划/冻结资源。到期依据绝对时点；跨季计划按原时限继续，不自动撤销或再冻结一份资源。不得季末强制清仓、支付奖励资金、重置钱包或重抽经济阶段。

结算记录初始本金、规则版本、种子、季初/季末净值、期末现金、当季收益率、当季最大回撤、累计净值倍数和同区间虚构指数表现。首季期初为玩家入场净值，续季期初为前季末净值；分母为 0 时相应比率显示不可用。新季可以重置当季计分的峰值，累计回撤峰值和所有市场状态保留。各市场指数以固定初始流通股数加权的价格总额计算并在玩家入场归一为 100；其变化只来自实际价格，不因赛季换算重新改历史。

固定本金挑战只将首次开局的 250 日成绩与相同规则的首季比较；续季作为该生涯履历保存，自选本金另列。首版不设固定最终生涯年限，但发布门槛包含连续 1,000 日验收；更长时期的经济、内容与存储效果不能预先宣称稳定。

玩家可在暂停时主动退休；资本耗尽采用账面净值低于本局原始本金 1% 且连续 5 日，由玩家确认结束。低现金、冻结或一笔未成交不触发，跨季不重置连续天数。由于可能尚有残余资产，名称使用资本耗尽而非债务破产。退出浏览器/保存退出不是退休。

财富里程碑初值为开局本金的 5/20/100 倍，且相应现金余额持续 5 个收盘达标；达到里程碑可继续。预留单冻结资金仍属现金，尚未卖出持仓不算现金。固定本金挑战与自选本金沙盒分开记录，里程碑难度不宣称跨本金相同。

里程碑倍数始终相对本局原始本金，跨季不重置资格、已达成标记或连续达标天数；未来“富可敌国”仍需另设与经济规模匹配的生涯目标，本版没有承诺 250 日达成。

## 9. 不变量与实现接口

必须保持：现金/可售/锁定/冻结股份非负；冻结资源是总余额的子集；全体股份守恒；交易现金含服务账户守恒；每股每批双侧成交股数相等；同一事件效果只应用一次；同一批不能用尚未收到的出售款；固定指令的快进与逐批结果一致。

模拟核心对外只需暴露创建世界、提交指令、推进至决策点、读取公开快照、导出/恢复存档。UI 不得直接修改价格、余额或解锁状态。内部经营、参与者、清算与总账可以分别验证，但不把每个内部状态都变成外部可写接口。

随机流按世界、行业、公司、事件、账户、分配平局隔离，键由实体与连续世界时点决定，不由函数调用次数或赛季编号决定。存档包含所有真实状态、公开历史、主体记忆、持续目标及复核时点、委托、计划、费用余额、赛季记录、形态确认时点及版本。初始化和每个数值步骤的舍入协议必须随实现版本固定；跨浏览器逐位重放要经黄金回放检验，不能仅凭 seed 承诺。

本附录关闭了“由谁定价、谁能知道什么、现金怎样流动、何时可以成交”的设计空白。参数是否产生足够交易与有趣机会仍按 [验证方案](./model-validation.md) 判定。
