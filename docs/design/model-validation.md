# 玩法模型验证与进入开发的门槛

版本0.3.1，2026-10-01。对应[主设计](./gameplay-market-model.md)与[精确规则](./market-model-rules.md)。P0补齐保护状态机反例、双市场及工程合同；本文区分设计/技术试验与原型实现验证，不能把前者当成完整游戏测试。

## 1. 本轮已完成的核验

0.1 阶段完成模型路线对比及两路独立交叉审阅，并据反馈修改了目标持仓重复扣量、分批费用冻结、缩量后费用超支、价格保护停滞、ADV 容量收缩、事件经报告重复外推六类问题。0.2 本轮是文档设计更新，没有完成模拟器、玩家测试或新增行为实验；下列原有算术结果不代表本轮新增机制已经通过。

已运行 [算术核验脚本](../../tools/design-checks/check_model_arithmetic.py)：

```text
python tools/design-checks/check_model_arithmetic.py
```

脚本只验证清算与配额算术，不是游戏模拟器：

- 5 个固定清算/分配算例通过。
- 2,000 组小整数价格市场中，“断点＋相邻 tick”搜索与逐 tick 穷举结果相同。
- 上述样本中委托输入顺序不改变结果，买卖双方数量分配和等于清算量。
- 同价按账户聚合后，拆成六张单不改变账户获配量。
- 行业、概念关系及账户数量的加总通过。
- 2,000 组费用分批分割满足所选预留上界；跨股缩量后手续费仍可能超支的反例与减量处理通过。

尚未验证完整总账、T+1、事件引擎、NPC 行为、长局、性能和好玩程度。2,000 个算例也不是对全部可能委托集合的形式证明。

0.2 本轮另核对了文档本地链接与代码块配对、目标向量插值算例、赛季日序边界及预热/长局计算量；原有算术脚本仍通过。这些检查不执行新 NPC 行为、形态识别或跨季存档流程。

## 3. 市场必须先能持续运作

P2第1轮失败引入的 `NPC-QUOTE-01` 合同回归使用[npc-quote-candidate.json](../../tests/scenarios/p0/npc-quote-candidate.json)的两个真实输入：原A001最高买4911/最低卖5164、原A003最高买4837/最低卖4875均无交叉；新有界目标缺口报价分别为指定买卖5500/5043和4837/4479分。先按固定本人输入通过生产报价/统一预算生成有限订单，再用实际统一清算对照；这些定向输入不冒充新世界经济。还须核对±.12边界、同目标成交后的剩余需求缩小、现金/可售股支持、旧档无字段的原行为与规范字节、未知版本原子拒绝。正式结果由生产核验记录；报价候选未证明90%×80%，原两种子须重新250+5，原100+10仍需新版本完整实际运行。

先关闭复杂主题和突发事件，只保留公开经营、价值、库存再平衡和噪声。每个世界先完整预热250日，再用两市各20股跑100个种子、玩家期250日；在运行前固定选定其中10个延长到1,000个玩家日，不按短期收益挑选。扩至200股公开版前，以全行为模型完成同样的跨季长期检查。

硬性要求：现金与股份守恒误差为零，负余额和重复结算为零，T+1违规为零；同版本同指令的逐批、逐小时、按日快进、存读档结果一致。

冻结原型检查线（0.3.1，未达须修复或凭证据回P0修订后全量重跑，不只解释放行）：

- 无重大事件40股基准，逐种子逐市场至少18/20股各在200/250玩家日真实成交；预热另250日，不计分母。
- 日换手中位数先以0.2%–5%为可诊断区间；持续偏离要查目标、预算和供需，而不是直接补造成交量。
- 任意一股连续零成交必须可区分“双方根本无交叉”与“价格保护阻断”；全市场长期停转阻塞后续扩内容。
- 价格保护、费用循环和T+1不得让某一账户无限获得新预算或库存。
- 股票不能因“没有被玩家点开”而暂停更新或改变概率。

这些范围是体验筛查标准，不是现实股市校准结果；达标也不等于好玩。

## 4. 验证四条玩法路径

每条路径至少有两个有利条件场景、两个失败场景。场景定义先固定，再跑策略，不根据结果临时改成“它本来就不适合这里”。

| 路径 | 有利场景 | 失败/取舍场景 | 观察指标 |
|---|---|---|---|
| 经营修复 | 经营改善、公开估值分歧、资金未充分配置 | 周期顶部误判，经营继续恶化，修复太慢 | 净收益、回撤、持有时间、相对基准 |
| 预期差 | 公开预期偏低、实际改善且尚有承接 | 结果低于预期，消息早已反映，传闻失实 | 公布前后预期版本、成交成本、收益归因 |
| 趋势/主题 | 多股扩散、关注持续、仍有资金预算 | 单股脉冲、过度拥挤、反转与T+1锁仓 | 扩散广度、追随成本、失败退出量 |
| 资金执行 | 平静深度逐步出现，分批减少冲击 | 趋势快速上行或流动性撤走，等待更贵 | 完成率、实际均价、未完成目标、时间 |

执行策略比较必须对未完成量负责。不能把“只买到最便宜的10%”与“买够100%”直接按均价判胜。预先声明目标数量、终止时间和机会成本口径；先报告成本—完成率关系，再评判策略。

### 4.1 技术形态的因果识别口径

下列是首版研发诊断与基准策略口径，不是向价格生成器写入的行情脚本，也不是实时必胜提示。小时与日线分别计算，当前 b 必须已经完成且有实际成交；观察窗口为此前20根，至少10根有成交。未达到条件的记录标为样本不足，不算作没有形态。

固定 U 为此前20根中有成交窗口的最高实际成交价，D 为最低实际成交价；不把当前 b 纳入参考区间。上/下缓冲分别为 max(1 tick,该参考水平的0.5%)（小时）或 max(1 tick,该参考水平的1%)（日线），比较使用精确比例，只有实际订单才按买向下/卖向上舍入。Vmean 是此前20根成交量的平均数，零成交窗口计0，不含当前窗口。两市使用相同诊断定义，再分别报告分布。

| 形态 | 当时可识别的条件 | 后续记录与失效 |
|---|---|---|
| 趋势条件及延续 | 连续3个已完成窗口同时满足MA5>MA20且收盘>MA20；向下对称 | 记录确认后5窗口的收益路径、最大顺逆向波动及是否跌破MA20；不能先看收益再决定是否计样本 |
| 区间突破 | 当前收盘>U+上缓冲；下破为收盘<D-下缓冲 | 冻结该次U/D与缓冲，观察后5窗口；后续滚动区间不改写该信号 |
| 突破后回踩 | 上破后1至5窗口内，某有成交窗口的高低区间与[U-缓冲,U+缓冲]相交且收盘>=U；下破后反抽对称 | 到回踩窗口结束才确认；若此前已收盘跌破U-缓冲则原突破先失效 |
| 假突破 | 上破后1至5窗口内首次收盘<U-缓冲；下破后收回D+缓冲以上对称 | 当该窗口结束才记失败，不能在突破当时预知；先回踩成功后又失败也保留两次事实 |
| 量价分歧 | 出现上述突破但当期V<0.75*Vmean | 记录后续结果，不直接判为反转或赋予卖出奖励；与普通突破分组比较 |

连续趋势条件只在首次进入满足状态时生成记录，条件中断后才能重新触发；同一股票、同一尺度的突破在5窗口观察期内不重复开同方向新样本，反向突破可以结束旧观察并另记。统计区分相关/重叠记录，以世界种子为分组单位报告，不把200股当成200个独立世界。

若诊断使用局部拐点，首版固定为左右各2根已完成且有成交窗口的严格极值；相等高低不选。拐点位于t时最早t+2完成才确认，且在存在零成交邻窗时标为不可确认，不压缩日历偷看。图上可以把标记画在t，但数据记录必须同时保存confirmedAt；基准策略只能在confirmedAt后的下一可操作批次行动。

### 4.2 多周期行为和技术玩法验收

先在固定公开输入的行为场景中验证角色按各自时点、窗口和lambda响应。再运行完整市场，观察成交持有时间、目标变化速度、短长信号分歧及预算占用，并单独统计常规、重大信息和风险触发的复核次数。若重大信息过密使长期账户几乎每小时全面换仓，应调整公开触发范围/门槛并重新验收。不能只证明配置表写了不同数字；若不同角色的实际行为始终相同，多周期设计未通过。

在保留种子上分别报告两市、大小盘和小时/日尺度的形态出现率、等待时间、失败率、识别延迟、执行成本和退出完成率。样本充分性预警初值：每市、每尺度、每类条件至少跨10个保留种子累计50条可识别记录；不足时报告缺口，不筛选漂亮股票或另造固定路径凑数。阈值是项目初值，不是现实市场比例或有效性的统计证明。

每条技术交易路径至少覆盖两种成立场景与两种失败/反向场景。量价分歧可以有信息但无独立收益；回踩后仍可能失败。验收重点是公开证据能支持有取舍的决策、错误能被后续证据识别，并在实际费用、容量和T+1约束下仍有玩法价值。不得要求每个形态都稳赚，也不得只凭形态出现次数宣布技术玩法成立。

### 4.3 赛季长度与跨季体验

60日体验用于学习和短线操作；250日用于标准赛季的机会密度、等待和结算；连续1,000日用于三个跨季边界、长期状态和内容重复检查。所有时长都另加250日预热，不把预热算作玩家经历。250日不足以自动证明完整波浪或牛熊周期，也不以浪数齐全作为通过条件。

场景必须包含第240日附近产生、结果在第260日以后公布的公开事件链，以及跨季保留的波段目标与玩家执行计划。验证快进结算后继续能处理原判断，所有成熟日期和随机键保持连续；结算页既不能泄露尚未公开的结果，也不能因新赛季重新抽签。

记录玩家每季主动决策次数、强制/条件暂停次数、无操作等待和现实用时，并确认其理解“成绩已结算、世界继续”。这些数据用于决定默认节奏或是否调整赛季长度；不先承诺250日等于固定几小时游玩。

## 5. 基准策略、保留样本与信息价值

基准包括持币、分散持有、风险和换手匹配的随机交易、公开价值信号、公开预期差、短线趋势、波段趋势、突破与回踩、主题轮动；执行基准包括一次提交、保护限价和分批。技术策略必须预先固定确认条件、入场批次、保护价、退出/失效条件与最大持有期限，再在保留样本运行；不得按事后峰谷最优成交。

先用30个固定种子调参，再在另外30个未参与调参的种子上初筛，每局120日；扩展确认时使用100个保留种子、每局250日。若参数因为保留样本结果而修改，该批种子转入调参集，重新生成保留集。

同一组比较共享初始化、外生事件与经营扰动，账户行为和价格根据各自交易自然分化。不能强行共享一条既定价格轨迹，那会抹掉玩家影响。随机流按主体与时点隔离，订单数量不能改变明天的新闻。

第一轮目标是：在预先指定的适用场景中，信息策略相对风险/换手相近的随机对照，在多数种子上改善净收益或风险的一项，并报告另一项代价。可用60%的配对胜率作为警报线，必须附样本数和区间；30或100个种子都不支持“稳定盈利”的宣传。任何策略都不必在所有环境里胜过持币。

必要消融实验：

- 去掉公开消息后，事件策略的优势应降低；否则可能读到了隐藏结果。
- 打乱概念成员后，主题扩散作用应减弱；否则题材只是装饰。
- 去掉持仓与现金约束后，大单冲击/退出困难应明显变化；否则资金模型没有真正参与定价。
- 将甲新股改为当日可售后，隔夜风险与日内纠错应出现差异；否则T+1只是界面标签。
- 保持资金和股份不变，分别关闭技术价格信号、把所有角色改为短线观察与同频复核，比较不同尺度的形态和策略结果；不能通过删掉资金账户来冒充行为消融。
- 用打乱历史收益顺序的离线对照检验形态识别与未来数据泄露；该对照不具备原模型的订单簿、成交量或执行条件，不能据此报告可成交利润，也不能单凭差异就验证整套技术理论。

## 6. 对抗策略与机械获利

扫描以下路径：小单抬最后价、刷同一概念成交、同价拆单抢分配、反复撤单释放两次现金、提前花卖款、拉股A推高公开主题后卖股B、费用周期前后交易、利用扩带触发器推价、存档重抽消息。

控制实验先关闭经营变化、事件与其他账户的趋势跟随，使用真实有限库存与现金，不恢复成交过的旧报价。往返买卖不能凭结算规则创造总财富。完整市场里允许某次影响他人后获利，但不能出现跨环境反复执行、容量可无限扩大而几乎无亏损的循环。

发现确定的账务/信息漏洞立即阻塞；疑似策略优势先报告收益分布、资金规模、成本、失败种子和是否依赖对手愚蠢。不能仅凭一次赚钱判为漏洞，也不能以“真实市场也能操纵”为理由接受无限提款机制。

## 7. 玩家与性能验证

找6–8名目标玩家，每人试玩30–45分钟，含一个经营局面和一个小时级局面。至少约三分之二能解释交易理由、反证、部分成交与新旧仓区别；多数应能说明何时愿意切换操作周期。若玩家只能总结“看到好消息就买”，优先改信息与因果反馈。

扩到200股后测定桌面Chrome/Edge/Firefox/Safari及至少一台中端移动设备。报告机器、浏览器版本、250日首次预热与缓存恢复时间、单日推进、取消快进延迟、跨季存档恢复和长局内存；手机首版的完整布局仍需另行安排。缓存比较必须恢复完整相同世界，而不只是图表。

200股×16批×250日＝每年80万股票批次；每股12本地＋2跨市场账户，最多约1,120万次有效账户—股票评估/年，三档委托、排序与统计另计。这个数字是循环预算，不是性能证明。优先检查一日推进目标200ms、长快进可取消、预热不长时间阻塞界面；未达标先定位，不能改成观察到才更新股票。

新版预热250日自身再增加80万股票批次；“预热＋首季”为160万，“预热＋连续1,000玩家日”为400万股票批次，对应约2,240万和5,600万账户—股票报价评估上界。慢速目标减少目标重算频率，但所有账户仍须执行资源检查和必要报价，不可直接按复核次数声称总成本等比下降。日线与运行中指标采用滚动计算，单批不重新扫描整段历史。

## 8. 决策闸门

| 闸门 | 通过条件 | 不通过时处理 |
|---|---|---|
| G0 规则可实施 | 固定算例、资源冻结、事件覆盖和信息顺序均有确定答案 | 修改设计后重跑相关规则检查 |
| G1 经济可运行 | 账务零违规；基准市场能长期真实成交 | 只调整初始化和行为参数，不补造资金/成交 |
| G2 四条路径成立 | 每条有可观察取舍；多周期行为有差异；技术识别无未来信息，日/小时模式均有价值 | 调信息与行为反馈，暂不扩内容 |
| G3 无已知提款漏洞 | 对抗路径无确定账务/信息套利，疑似循环有证据解释 | 修复并加入回归场景 |
| G4 可公开试玩 | 200股性能与信息负担可接受；250日预热与连续1,000日验收通过；跨季状态连续，玩家理解规则 | 缩表现和内容负担，保持核心交易合同 |

本轮只通过了 G0 中的清算与配额算术子项，完整 G0 和 G1–G4 均待原型实现。现在可以开始实现已定规则；不能据此跳过模型验证直接承诺最终平衡。
