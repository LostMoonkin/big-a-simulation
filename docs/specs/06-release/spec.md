# P6 — 可复现静态发布与交付

状态：未开始。输入为 P5 已验收的 RC；输出为静态发布包、可访问预览及完整运行资料。
关联：[路线图](../README.md) · [实施计划](./plan.md) · [任务](./tasks.md) · [引擎研究](../../research/engine-feasibility.md)。

## Goal

让接手者从指定版本构建、启动和验收同一款游戏，让玩家打开页面即可开始或恢复本地生涯。
发布交付不依赖账号系统、后端或尚未选定的托管服务；本地静态预览即可完成本阶段验收。

## Behavior

- 发布包能由普通静态 HTTP 服务提供，页面、Worker、字体、图表及内容正确加载。
- 首次进入可新建游戏；已有兼容存档可以恢复；导入失败时保留原有进度并说明原因。
- 首屏控件就绪与默认新局可交易分开验收；默认桌面开局沿用 P5 的 p95 ≤ 10 秒初值，任意种子长预热单列并显示进度/取消。
- 玩家能够查看快速开始、交易规则简化说明、本地存档备份方法、已知问题及反馈入口。
- 版本页可查应用、模拟规则、内容和存档格式版本，反馈可附版本、公开种子及复现步骤。
- 世界中的市场、公司、人物、事件和新闻全部虚构；适用的软件许可与归属通知清楚可见。
- 接手者能从交付目录找到发布文件、摘要、构建说明、验收证据、升级/回滚步骤和兼容表。
- 当前静态版本和上一已验证版本可以切换；回滚必须保留当前存档及兼容快照，不能自动清空进度。

## Constraints

- 必须消费 P5 已验收的候选，不在发布阶段静默修改规则、内容参数或依赖版本。
- 依赖与构建工具版本锁定；构建过程不依赖未记载的本机文件、全局包或开发服务。
- 发布资源使用可验证的目录和引用关系；以最终交付目录启动，不能拿开发服务器通过代替发布包通过。
- 运行版本、规则、内容和存档兼容关系显式记录；不兼容时明确拒绝或按已实现迁移处理，不猜测恢复。
- 单人本地档允许导出备份；反馈导出只在用户主动触发时生成，不收集后台遥测或自动上传完整存档。
- 公开 URL、域名与托管账号是以后实际部署时的输入，不是本轮写 specs 的前提，也不阻塞本地交付验收。
- 页面剧情的虚构要求不能用来删除第三方许可或必需归属。
- 若发现构建差异、许可证缺漏、存档丢失或核心冒烟失败，修复后按影响范围返回 P5 复验。

## Out of Scope

- 现在注册域名、购买服务、上传到未知账户、创建账号系统或运行后端。
- 云存档、排行榜、联网竞技、在线付费经济、监控平台和自动采集玩家行为。
- 保证任意旧存档可迁移，或让旧版本读取其无法理解的新存档。
- 扩展手机完整 UX、债券/期货/ETF 等新资产及其他新增玩法。

## Acceptance Criteria

- **P6-AC1 可复现包：** 从记录的干净源版本、锁文件和工具版本构建两次，静态有效载荷文件摘要一致；归档时间等非运行元数据单独说明。交付包不存在开发服务依赖或缺失资源，摘要清单可校验。
- **P6-AC2 可访问交付：** 使用交付目录通过本地静态 HTTP 服务或已授权静态预览打开游戏，完成新局、交易、快进、保存、关闭重开和恢复。按 P0/P5 固定空缓存/网络条件分别核验首屏与默认桌面可交易时间（初值 p95 ≤ 10 秒），不能用可取消长预热替代。采用预置完整快照时须随静态包分发且与匹配重算一致；给出访问方式及证据，不要求公网 URL。
- **P6-AC3 版本与兼容：** 交付版本清单和存档兼容矩阵，覆盖当前档、上一兼容档/迁移夹具、未知新版本及损坏档；拒绝不兼容输入时原档不变。没有历史正式版时用固定前序 RC 作为演练基线，明确其身份。
- **P6-AC4 玩家资料：** 快速开始覆盖小时/日决策、T+1/下一批可售差异、部分成交、真实成交 K 线、暂停、250 日结算后继续、本地档导入导出；反馈入口可输出版本及用户选定的复现资料，已知问题与适用浏览器明确。
- **P6-AC5 虚构与许可：** UI、教程、全部公司/事件内容及内置示例完成虚构审查；依赖许可清单、分发通知、字体/图标来源和图表归属满足已锁定版本要求；真实机构名只在必要许可或研发资料中出现，不混入游戏世界。
- **P6-AC6 发布前验证：** 在最终包上完成四桌面浏览器关键流程冒烟和一台中端移动设备技术回归，使用真实 Safari；P5 证据与最终版本可关联，任何影响规则/状态的差异必须重验。
- **P6-AC7 可恢复回滚：** 在独立测试浏览器档案/存储副本中完成升级→保存→回滚演练；兼容时可继续，不兼容时保留新档并恢复兼容备份或提示返回新版本。不能删除、覆盖或伪造已完成进度。
- **P6-AC8 交接完整：** 发布目录、包摘要、快速开始、构建/启动/故障与回滚说明、版本兼容矩阵、许可、已知问题和验证索引齐全；状态清楚区分“已交付本地发布包”和“已部署公网”，不得把未部署记为部署成功。
