# P3 实施任务

状态：未开始。[Spec](./spec.md) · [Plan](./plan.md) · [阶段总览](../README.md)

拆分结果：4 个纵向 Ticket。事件可解释性、两市政策与主题、多周期观察、四条路径实测分别有独立验收结果；前两项是后续策略实验的输入，最后一项依赖完整交易反馈，继续合并会失去逐步定位模型问题的边界。

## P3-T1 — 玩家能追溯公开预期与实际结果

状态：未开始。

### Outcome

玩家在浏览器经历预告、结果、经营落地、报告覆盖和证伪，并能查看旧预期；回放证明同一结果只应用一次。

### Scope

1. 从 P0 的正式模板表实现代表内容子集和稳定分支排程；内部结果与公开版本使用不同读取边界。
2. 实现事件渠道、ID/覆盖期间去重、持续影响余量、报告外推剔除及未兑现预期的到期更新。
3. 接入公共窗口与既有暂停/委托流程；刷新 NPC 报价，保留玩家撤改单机会及本小时真实余量。
4. 完成消息列表、事件详情、历史预期比较和持仓相关通知；通知选择不得反向影响事件生成。
5. 把 A12、A15 及一次性/持续/证伪/过期/部分报告覆盖写成可回放场景，保存事件轨迹和浏览器演示证据。

### Acceptance

- 对应 P3-AC1、P3-AC2、P3-AC10；事件场景重复恢复、重复查看不会重复修改 E 或公开预测。
- 结果公布前正常公共快照无隐藏结果，公布后不能利用 NPC 过期报价获得保证成交。
- 本 Ticket 交付可独立操作的消息到交易闭环，不只交付事件数据类型。

### Depends On

- P0 冻结事件/市场合同；P2 通过。

### Not Included

完整 24 模板/6 链的文本量；基于真实公司新闻的内容生成。

## P3-T2 — 玩家能比较两市政策与主题扩散

状态：未开始。

### Outcome

相同或相关的公开信息在两市产生符合 profile 的不同预期、资金响应和成交路径；玩家能从主题面板看到扩散及落空。

### Scope

1. 按 P0 的实际政策字段、传导渠道与资金参数实现两市差异，逐项连接公开信息、经营/估值、目标、有限订单。
2. 实现关注、三家门槛、持续性、方向及拥挤计算；业务暴露合成时去重同一渠道影响。
3. 完成两市政策摘要、公司业务关联、主题成员及历史扩散展示，隐藏 NPC 精确持仓与未来链阶段。
4. 运行 P0 的全部市场特色场景、单股脉冲、跨股扩散、负面高关注、过期和双概念去重场景。
5. 生成同外生流、不同市场参数的行为对照及参数关闭的消融证据；不强制共享价格轨迹。

### Acceptance

- 对应 P3-AC3、P3-AC4、P3-AC10；输出的市场差异能追溯到公开渠道和有限委托。
- 8 个代表模板/2 链覆盖两市所需机制，计入正式 24/6 总量；无政策或热度直接修改价格的路径。
- 历史扩散统计不被单个股票刷量或两标签重复放大。

### Depends On

- P3-T1；P0 的双市场 profile 与期望场景已冻结。

### Not Included

为保证出现特定市场形态而预写 K 线、额外注资或强制结果。

## P3-T3 — 玩家能进行小时与多日技术判断

状态：未开始。

### Outcome

玩家使用 MA 和手工参考线观察不同时间尺度；策略在实际确认后行动，多周期账户的目标变化速度可复核。

### Scope

1. 在 P2 的原持续目标实现中启用三层信号及技术/主题项，保持排程、插值、风险和容量语义不变。
2. 记录目标复核原因和前后值，覆盖普通复核、重大消息合并、风险减仓与复核之间成交。
3. 增加指定 MA、水平线/趋势线及删除操作；显示无成交、未完成和指标不足，不将界面操作计为世界事件。
4. 按冻结口径实现趋势、突破、回踩、假突破、量价分歧和拐点研发记录，分离图上位置、确认及下一可行动时点。
5. 执行 A20–A24、A29–A31、两种未来共享历史前缀对照，以及各类技术路径的成立/失败场景。

### Acceptance

- 对应 P3-AC5、P3-AC6、P3-AC7、P3-AC10；相同前缀不因未来变化重写信号或订单。
- 日级目标不读取未完成日线；慢速目标在复核间保留，重大消息/风险不会刷新小时容量。
- 图表工具与诊断均能独立演示，正常 UI 不出现确定性浪数或研发隐藏状态。

### Depends On

- P3-T1（重大信息合同）；P2 持续目标和公共行情接口。可与 P3-T2 并行，最终启用主题项需其通过。

### Not Included

周/月 K、自动波浪计数、产品级标注存档；标注在 P4 随生涯保存。

## P3-T4 — 四条路径完成演示和保留样本初筛

状态：未开始。

### Outcome

交付可运行的四条玩法演示、预注册策略及首轮初筛报告，清楚说明每条路径何时成立、如何失败及交易代价。

### Scope

1. 写明策略可读信息、确认、入场/退出、最长持有期、资金量及执行方式，形成冻结配置和命令清单。
2. 为经营修复、预期差、趋势/主题、容量执行各制作成立与失败的可复现浏览器操作记录；场景只固定输入或种子，不覆盖清算价。
3. 运行 30 调参/30 保留种子、每局 120 玩家日及 250 日预热；完整模型均从建世界启用，训练与保留清单分离。
4. 完成消息、概念、技术/频率、资源和 T+1 消融，输出配对收益/风险、失败率、等待、成交与退出成本。
5. 接入 `npm run verify:p3 -- --out artifacts/verification/p3/<run-id>` 与批量执行入口，归档全部 AC、场景、配置及演示证据。

### Acceptance

- 对应 P3-AC8、P3-AC9、P3-AC10，并汇总 P3-AC1–7；P1/P2 不变量零回归。
- 玩法没有取得可解释取舍时明确阻塞扩内容，不能只以报表生成成功判定 G2 通过。
- 保留结果参与新调参后，原保留集撤销保留身份，另建样本；失败种子和不足类别不从结果中删除。

### Depends On

- P3-T1、P3-T2、P3-T3 全部通过。

### Not Included

全面 100 保留种子确认、完整 1,000 日平衡或公开发布性能；这些在 P5 验收。
