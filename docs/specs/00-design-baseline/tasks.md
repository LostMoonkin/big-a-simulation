# P0 实施任务

状态：P0-T1/T2/T3均已实施交付、待独立验收。拆分为3个可独立审阅的交付任务：市场机制合同、原型/时间场景合同、工程/实验合同。文档本身就是本阶段成果；[交付报告](../../verification/p0-baseline.md)逐项索引证据，最终按[spec](spec.md)核对，具体顺序见[plan](plan.md)。

## P0-T1 定案两个市场的政策、资金与价格发现机制

**Outcome**：实现者能依据冻结规则产生两市差异，审阅者能演算信息到成交的路径及失败场景。

**Scope / 实施步骤**：

1. 列出D01/D02当前未定项及对应0.2段落，先定义可观察的玩家决策差异。
2. 写出共享与本地状态、业务暴露、公开预期/经营/估值的作用公式、参数和时间；查证新增现实参照的一手资料，游戏值单独标初值。
3. 确定两市资金反应差异及政策事件、业绩指引等代表场景；明确来自正式24模板/6链的哪些内容位置。
4. 对价格带边界成交、连续受阻、无交叉需求、恢复报价完成固定演算，选择并记录重开规则。
5. 更新权威设计、受影响A13/A14和新增市场场景；编写至少每市2成立+2失败场景的公开时间线和预期结果。

**产物**：计划文件`docs/design/market-identities.md`、带新版本的模型规则与验证案例、D01/D02关闭记录及D08内容约束。

**Acceptance**：P0-AC1/AC2/AC3；所有价格都可追溯到真实有效委托，没有指定浪形、隐藏NPC先知或免费资金来源；两市差异可用交换profile实验检验。

**Depends On**：现有0.2设计与研究。

**Not Included**：实现整个市场引擎、引入真实证券/新闻、宣称所有特定形态必然出现。

## P0-T2 固定40股原型和跨赛季信息场景

**Outcome**：同一世界机制有可满足约束的原型配置，预热、事件到期和赛季边界不会要求互相矛盾的实现。

**Scope / 实施步骤**：

1. 按plan的建议边际生成原型行业×市值配置及8概念业务关联，检验每股标签上限、成员跨行业及38条关系总额。
2. 以真实股份和26钱包演算初始化分配，列正式/原型唯一可变配置；记录资金相对容量的变化。
3. 将第240日到第260日以后事件写成包含20日内公开更新/过期处理的完整时间线。
4. 核对250日预热所需指标端点、世界时钟、费用/复核相位与玩家入场；完善跨季计划、锁定股和里程碑场景。
5. 联合P0-T1完成P3代表模板/链映射，确认没有超出24/6总量或新增隐含资产。

**产物**：正式/原型配置样本、配额校验记录、跨季场景数据、D03/D04/D08关闭记录及权威规则必要修订。

**Acceptance**：P0-AC4/AC6；配置实际可满足而非只有总数正确；第250日没有重抽行情，尚未公开结果不进入玩家/NPC信息。

**Depends On**：可与P0-T1并行起草；最终整合依赖其市场与事件合同。

**Not Included**：完成200家文案、P4耐久存档或P5长期经济测试。

## P0-T3 冻结核心Interface、数值方案与验收协议

**Outcome**：P1有可执行的工程起点和确定性检查输入，所有后续阶段知道如何证明交付成立。

**Scope / 实施步骤**：

1. 明确账务整数表示、乘法上界、舍入与序列化；选定随机流键和可跨端核对的数学方案，制作边界输入。
2. 定义创建、命令、推进、公开查询、完整快照Interface及错误/重复/过期语义；明确公开准备后的安全决策点、清算与记账原子提交、手动取消边界及阶段恢复；用公开与私有样本检查未来信息隔离。
3. 进行最小图表/Worker/静态构建/存档编码技术试验，核验实际工具版本与许可证，记录失败及替换理由。
4. 固定逐种子逐市场基准、训练/保留清单协议、设备档案、性能初值和证据目录；定下默认种子及快速开局方案、完整预热快照与重算一致合同。分开定义空缓存首屏p95≤3秒和默认桌面可交易p95≤10秒目标，以及任意种子60/180秒现场预热预算；更新跨阶段追踪矩阵。
5. 整合D01–D08状态、设计版本、受影响案例和技术试验，出具P0出口报告；未完成项不得标为已关闭。

**产物**：计划文件`docs/design/engineering-baseline.md`、可复现最小试验、数值黄金样本、实验/设备协议、`docs/verification/p0-baseline.md`。

**Acceptance**：P0-AC1/AC5/AC7/AC8，并联合P0-T2复核AC6工程合同；预热和交易不依赖UI帧率，账务不丢精度，命令和快照可识别版本；原型与最终验收协议明确。

**Depends On**：数值/工具试验可并行；最终基线依赖P0-T1、P0-T2交付。

**Not Included**：正式应用脚手架以外的大规模实现、未实测的性能通过结论、要求外部托管权限才能完成设计。
